# Online Shop

Build an online shop with a product catalogue, shopping cart and checkout.

Requirements:
- Customers browse and search products by category and price, and view product details with images.
- A shopping cart keeps items between visits; checkout collects address and payment details.
- Payment is handled through an external payment provider API and order confirmation e-mails are sent.
- Administrators manage products, stock levels and orders, and see a daily sales report.
- Products, customers and orders live in a relational database.
- The system exposes a REST API used by the web front end; stock must never go negative under concurrent orders.
- Provide integration tests for the checkout flow and deployment documentation.
