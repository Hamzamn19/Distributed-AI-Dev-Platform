# To-Do Application

Build a simple to-do application with a REST API, a database and a web front end.

Requirements:
- Users register and log in, then create, edit, complete and delete tasks.
- Tasks have a title, description, due date, priority and optional tags.
- Users can filter tasks by status, tag and due date, and get a reminder list for tasks due today.
- Tasks are stored in a database; each user only sees their own tasks.
- The web interface is responsive and works on mobile screens.
- Include unit tests for the task logic and basic API documentation.
