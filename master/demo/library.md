# Library Management System

Build a library management system with a REST API, a relational database and a web interface.

Requirements:
- Members can search books by title, author or ISBN, borrow available books and return them.
- Each loan lasts 14 days; overdue loans must be flagged and listed for librarians.
- Librarians can add, edit and remove books and manage member accounts.
- Data (books, members, loans) is stored in a relational database with migrations.
- The REST API is authenticated and documented (OpenAPI).
- The web interface offers a search page, a "my loans" page and an admin panel.
- Provide automated tests for the API and a short user guide.
